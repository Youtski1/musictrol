# musictrol

Музыкальный виджет для рабочего стола Linux: полупрозрачная «стеклянная» карточка,
капсула-пульт, мини-виджет с панелью поиска и режим караоке «Орбита».
Музыка — с YouTube, текст песни идёт построчно вместе с треком.

> Проект в разработке. Сейчас готов шаг 1: поиск и воспроизведение (временное тестовое окно).

## Стек

- Qt 6 / QML + C++20
- libmpv — воспроизведение (только звук)
- yt-dlp — поиск и получение звука с YouTube

## Сборка (Arch / Manjaro)

```bash
sudo pacman -S --needed qt6-base qt6-declarative cmake ninja mpv yt-dlp
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build
./build/musictrol
```

## План

1. Каркас и воспроизведение с YouTube ✅
2. Главный виджет (стеклянная карточка, настройки)
3. Мини-виджет в углу и панель музыки по центру
4. Капсула-пульт с волной
5. Караоке «Орбита»
